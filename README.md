# FUTARI｜カップル相性診断

二人が同じ質問に答え、4つの恋愛軸から相性と関係を深めるヒントを表示するWebアプリです。

## 主な機能

- カップル／付き合う前の2モード
- 8問のライト診断／16問のじっくり診断
- 二人専用の共有URL
- 相性スコアと4つの恋愛軸
- 二人の取扱説明書
- 7日間チャレンジ
- 結果カードの画像保存

## ローカルで起動

Node.js 20以上が必要です。

```bash
npm start
```

ブラウザで `http://127.0.0.1:4173/` を開きます。

## Cloudflare Workers

`worker.js`、`wrangler.jsonc`、`schema.sql` を使って、暗号化された共有セッションをD1へ保存できます。

回答データや暗号鍵などのローカル秘密情報はリポジトリに含めていません。
